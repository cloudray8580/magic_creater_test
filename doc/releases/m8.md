# M8：创作草稿、永久删除与体验修复

## 使用方式
1. 从首页打开模板不会产生作品；第一次修改后保存本浏览器草稿，点击“保存到服务器”才建立服务器作品。
2. 我的小世界只显示自己的作品与本地未同步稿。新账号为空；历史作品仍保留，可自行整理。
3. 卡片“删除作品”需要确认；确认后移除作品、全部提交版本及反馈，无应用回收站。账户共用素材、独立改编、既有备份和已导出文件保留。
4. 本地草稿仅在当前浏览器；原作品被另一设备删除后，可从救援草稿导出或另存副本。

## 游戏体验
修复缩小反向放大、出生点删除、长对话溢出、移动桥过薄、巡逻素材不一致、互动提示边界。必需与额外收集分开计数；受阻终点说明缺项；倒计时和拾取提示分开；同名拾取也保留可读提示；重生/重开立即回到人物。

本阶段地图仍为原上限。后续M9/M10分别扩展至512×64和目标2048×64，须以性能报告验收。

## 演示与发布
[一分钟演示及附件](https://github.com/cloudray8580/magic_creater_test/releases/tag/m8)。发布附件包含MP4、封面、中文字幕及录制清单。录制工具 scripts/record-release.mjs 在11700运行真实浏览器，使用临时数据库与虚构账号，不连接正式业务数据；只录制本版本已有功能。

工具依赖：11700用户目录下的ffmpeg-static 7.0.2与ffprobe-static；通过FFMPEG/FFPROBE环境变量可改工具路径。运行前npm run build，再node scripts/record-release.mjs m8。录制需与发布源码commit一致；artifacts/releases/m8记录时长、尺寸、源码commit与SHA256。视频为中文字幕，无配音。
