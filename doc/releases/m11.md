# M11 雪人回家：边走边救援

新增第三种创作玩法。创作者在最长128×128格的雪地中布置道路、破路、缺口、火堆、树荫、冰面和拾取物，设置雪人的初始体积、准备时间及玩家可用的木材、清水、路牌和雪球。帽子有四款外观，拾取后按顺序逐顶叠高；胡萝卜会装在雪人鼻子上。

玩家可先阅读地图。点击开始后默认有3秒准备时间；时间结束雪人自动寻找回家路。雪人出发后玩家仍能在它前方修路、架桥、灭火、放路牌、滑雪板和雪球。雪球经过时补充8点体积，上限为初始体积的150%；破路和断桥会让雪人在前方等待救援。旅程可暂停，手动拖看远处时镜头不会抢回雪人；结果可回放，未使用的布置可以撤回。

创作者亲自用当前版本通关后，才能提交老师审核；同伴试玩与反馈沿用现有班级流程。服务器依据作品版本和带时间的操作记录重新计算结果，拒绝超额材料、非法操作和旧修订。旧版格子与双玩法作品保持可用；此前未发布的雪人实验草稿可转换到新规则。

本版面向11700主机上的电脑键鼠小范围试用。移动端、真实课堂规模及公开发行资格不在本次验证范围内。操作录像与验证记录在本版发布附件和 [验证文档](../task_plan/snowman/09-verification.md)。
