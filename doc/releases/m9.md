# M9 可扩展的小世界

- 横版地图可扩展到512×64，最多8192格地形、300个物体；文档上限1MiB。
- 一键向右扩展64格，小地图定位、起点/终点定位，缩放围绕视野中心。
- 只绘制附近地形；碰撞按空间查找；保留100步撤销与自动本地草稿。
- 列表只加载作品摘要，打开、试玩、导出时读取完整文档。
- 探索故事和旧版格子作品继续使用原有规则。
