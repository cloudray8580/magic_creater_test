# 04｜中国大陆发行、课堂使用与主要门槛

检索日期：2026-09-26。范围：中国大陆。香港、澳门、台湾及海外发行需另行研究。本章区分法规要求、渠道规则和本项目判断；具体形态的最终归类需要当地主管部门、学校及发行伙伴确认。

## 1. 先决定产品实际是什么

不能仅靠名称“教育”“公益”“免费”“H5”“单机”判断是否需要游戏审批。应描述实际功能、谁能访问、联网方式、是否有账号/UGC/收费以及如何分发。

| 实际形态 | 初步判断 | 下一步 |
|---|---|---|
| 开发者内部原型，不向学生或公众分发 | 可先做实现和成年人可用性测试 | 固定边界，测试合成数据 |
| 教师在少量设备上组织离线创作活动 | 与面向公众网络游戏不同，但不能承诺自动豁免 | 学校审查活动、软件与数据方案；必要时问当地教育/出版主管方 |
| 校内局域网、班级账号、共享可玩关卡 | 封闭程度降低传播风险，联网服务和游戏属性仍需判断 | 不把“有口令”当作免审依据；确认具体经营与服务方式 |
| 公网课堂 SaaS、学校付费、学生登录 | 互联网、教育应用、数据与安全义务；若实质为网络游戏，还涉及游戏监管 | 尽早完成书面产品分类咨询 |
| 公开玩游戏、编辑关卡和社区分享 | 游戏出版与运营、UGC、未成年人保护等多重要求 | 与合格出版/运营伙伴合作，制定发行项目 |

国家新闻出版署国产网络游戏申报指南明确覆盖客户端、网页和网络下载单机游戏等。因此，“只在浏览器跑”“游戏不收费”“是单机下载”都不是通用免版号结论。[审批指南](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html)

## 2. 常被混淆的资格与手续

| 名称 | 解决什么问题 | 本项目应如何理解 |
|---|---|---|
| 著作权/软著证明 | 谁拥有或获授权使用程序及相关内容 | 不等于可合法出版运营；渠道对文件形式可能比法定申报更具体 |
| 网络出版服务资质 | 谁有资格作为出版单位 | 小团队通常与具备网络游戏出版范围的出版单位合作 |
| 游戏审批/版号 | 具体游戏内容的出版批准 | 绑定具体作品、主体和申报形态，不能借别人的版号套用 |
| ICP 经营许可证 | 相应经营性互联网信息服务资格 | 与“ICP备案”不同；国产游戏审批指南明确要求运营机构具有 ICP 证 |
| 网站 ICP 备案 | 网站互联网信息服务主体等信息登记 | 不能代替版号或经营许可 |
| APP/小程序备案 | 对具体移动应用及服务主体进行备案 | 已有网站备案不代表自动完成 APP 备案；需补充应用信息 |
| 平台小游戏备案 | 特定平台的游戏作品/前置备案流程 | 各平台和变现类型有差异；不能与 APP 备案、版号混为一谈 |
| 实名与防沉迷接入 | 未成年人识别、时长和付费控制 | 不是一个勾选项，需要服务端和运行流程实际生效 |
| 教育移动应用备案 | 教育 App 提供者/使用者的相关管理 | 不取代工信部备案，也不自动取代游戏审批 |

依据：[网络出版服务管理规定](https://www.nppa.gov.cn/xxgk/fdzdgknr/zcfg_210/bmgz_213/202112/P020221115748304315015.pdf)、[工信部 APP 备案通知](https://www.miit.gov.cn/jgsj/xgj/wjfb/art/2023/art_dd783a581c9644a4aee10afa582811db.html)、[教育移动应用备案办法](https://www.moe.gov.cn/srcsite/A16/s3342/201911/t20191122_409333.html)。

不要照搬旧的“文化部网络游戏备案 + 游戏网文证”教程：《网络游戏管理暂行办法》已于 2019 年废止。其他业务是否需要文化类许可应按实际服务判断。[废止决定](https://www.mct.gov.cn/preview/whhlyqyzcxxfw/wlrh/202012/t20201228_920272.html)

2023 年《网络游戏管理办法》征求意见稿也不能仅凭草案文本作为现行规则。本报告的操作结论依据已发布法规、规范性通知与现行官方申报/渠道页面，不把草案中的具体条款写成已生效义务。

## 3. 未成年人规则与课堂时段的冲突

2021 年通知规定，网络游戏企业仅可在周五、周六、周日和法定节假日每天 20:00–21:00 向未成年人提供一小时服务；所有网络游戏用户需实名注册和登录，不得通过游客体验绕开。[国家新闻出版署通知](https://www.nppa.gov.cn/xxfb/tzgs/202108/t20210830_666285.html)

**对本项目的关键推论：如果课堂工具的实际服务被认定为受该规则约束的网络游戏，老师带领并不能自行授予白天使用例外。** 这是需要优先确认的产品边界，不是等开发完后加一个 SDK 就能解决的问题。

2019 年通知中的未成年人付费限制，也需要与后续规则一起核验：未满 8 岁不提供付费；8 至未满 16 岁单次不超过 50 元、每月不超过 200 元；16 至未满 18 岁单次不超过 100 元、每月不超过 400 元。后续 2021 年通知收紧了时段，不能继续用 2019 年旧时长作为依据。[2019 年通知](https://www.nppa.gov.cn/xxfb/tzgs/201911/t20191119_666184.html)

本项目首版建议无学生付费、无广告、无抽奖、无连续签到惩罚。这样降低产品和伦理负担，但**不等于自动免除出版、备案和身份义务**。

## 4. 各渠道要求和适合程度

### 4.1 渠道矩阵

| 渠道/交付方式 | 已核实要求或路径 | 主要门槛 | 对本项目建议 |
|---|---|---|---|
| 校内离线软件/教师设备 | 没有找到适用于所有“教学小游戏”的一刀切豁免；看实际分发和用途 | 学校认可、安装权限、内容、监护与数据安排 | 最适合先做受控活动验证，完成校方确认 |
| 校内局域网 Web | 没有应用商店审核；仍需判断教育工具/网络游戏属性 | 学校网络、HTTPS、权限、维护、数据责任 | 第二步，小组互玩可由教师统筹 |
| 公网 H5/PWA 自有站 | 浏览器形式不排除出版监管；国内部署需相应备案和服务义务 | 版号/主体、备案、UGC审核、未成年人服务时段 | 不作为“快速绕过商店”的路径 |
| 中国大陆 App Store | Apple 明确游戏 App 需网络游戏出版物号；适用 App 需备案并核验主体信息 | 版号、证明材料、隐私/年龄分级、儿童类别规则 | 课堂 MVP 不优先；后期正式发行考虑 |
| 华为应用生态/快游戏 | 已核实快游戏上架要求游戏版权与版号，授权链及同名包内容一致 | 平台资质、SDK、包体验收；APK/HarmonyOS要求需另核 | 原生移动路线确定后单独接入 |
| 小米小游戏 | 2026 年审核规范列出版权证明、联网小游戏的 ISBN/备案识别码和主体授权一致性 | 具体资质形式、隐私、内容和登录/支付实现 | 不套用微信或其他平台的材料列表 |
| 微信小游戏 | 应分开核验主体、APP/小程序备案、作品备案、广告与内购资格、实名防沉迷；本轮未取得可完整核验的最新官方资质正文 | 后台规则随主体和变现方式变化，UGC能力限制也需确认 | 列为待后台核验项，不宣称“个人随便上架/广告游戏都免版号” |
| 抖音小游戏 | 官方提供作品备案流程；已有版号不重复申请该项；基本信息及版本审核通过后自动申报 | 主体、软著/授权、内容审核、变现资格及其他备案 | 可作为后期轻量发行候选，不能按该页面推断全部义务已满足 |
| TapTap 手机游戏 | 官方区分正式上线与开放试玩；有内购需版号等；无内购存在开放试玩路径 | 联网备案、防沉迷证明、隐私；测试不等于无限期商业运营 | 比直接全国正式上架更适合后期测试，但与课堂时段问题仍需分开 |
| TapTap PC | 官方测试表区分免费测试与付费测试；免费测试仍有防沉迷要求，付费测试要求版号 | 资格、启动校验、隐私、测试形式 | 适合有明确 PC 游戏发行目标时评估 |
| 蒸汽平台 Steam China | Valve 官方明确游戏需中国政府批准，产品页显示 ISBN | 中国出版/发行合作、内容与相关运营资格 | 后期正式 PC 发行路线 |
| 国际 Steam / itch.io | 是另一套平台分发合同和上架流程；Steam Direct 有每产品费用 | 税务、收款、当地法律、内容与儿童隐私等 | 不能据国际平台上架成功就认定在中国境内运营合法；单独规划海外市场 |

### 4.2 TapTap 和小游戏的差异为什么重要

TapTap 官方存在联网无内购开放试玩路径，同时要求备案、防沉迷与隐私；还可为符合条件的测试提供备案辅助证明。PC 免费测试表不要求先提交版号，但并不取消防沉迷。[TapTap 指南](https://developer.taptap.cn/docs/store/standardies-operation/)、[PC 测试表](https://developer.taptap.cn/docs/pc-store/guide/document-guide/)

抖音、TapTap 等小游戏的官方备案材料也说明，“小游戏备案”和常规版号发行存在不同流程。**应将这些视为平台指定的条件路径，不是“全部免费游戏免审批”的法律结论。** 是否支持你们的 UGC、课堂学生和变现方式，仍需给平台具体方案确认。[TapTap 小游戏前置备案](https://developer.taptap.cn/minigameapidoc/quick-start/guide/pre-filing/)

## 5. UGC 创作平台额外需要什么

关卡内容可以通过标题、文本、图像、音频、图案排列甚至规则表达不适宜内容，因此审核不能只覆盖聊天框。

建议的最小流程是：草稿 → 提交分享 → 教师/管理员审核 → 班级可见 → 举报/撤回 → 留存必要处置记录。更新后的版本重新审核，旧版和派生作品能追溯；下架原作时明确如何处理派生作品。

| 内容/行为 | 建议产品措施 | 性质 |
|---|---|---|
| 侮辱、欺凌、危险挑战、不适龄内容 | 提交审核、举报、处理时限、撤回和受限账号 | 结合未成年人网络保护义务的设计 |
| 真名、班级、住址、人像、联系方式 | 首版限制自由输入/上传；必要时人工检查 | 数据最小化设计 |
| 复制别人的角色、音乐、作品 | 素材许可台账、原创/授权记录、派生署名与投诉 | 版权和平台管理 |
| 私信、陌生人联系 | 首版仅小组活动，不开放私信和陌生人社交 | 本项目范围选择 |
| 恶意代码和外链 | 作品只保存受限数据；禁止任意脚本、HTML、外部资源URL | 技术安全要求 |
| 作品排名与流量 | 保证公平试玩机会，用具体反馈，避免公开排名 | 教育机制选择 |

《未成年人网络保护条例》对有害信息、个人信息和防沉迷等提出要求；具体适用条款应按产品功能逐项核验。[条例正文](https://www.miit.gov.cn/jgsj/zfs/xzfg/art/2023/art_60743e5d87b349099d24fdd54d77d8ab.html)

## 6. 未成年人信息和心理资料

《个人信息保护法》把不满 14 周岁未成年人信息及医疗健康等列为敏感个人信息，并规定处理儿童信息的监护人同意、专门规则等要求。14–17 岁仍受未成年人保护，不能因为满 14 岁就按普通成人产品处理。[个人信息保护法](https://www.npc.gov.cn/WZWSREL25wYy9jMi9jMzA4MzQvMjAyMTA4L3QyMDIxMDgyMF8zMTMwODguaHRtbD9yZWY9aW1i)

本项目建议：

- 学生使用班级内昵称/随机编号；真实名册由学校单独保管；编号仍可能关联个人，并不自动成为匿名数据。
- 无需记录病史、诊断、家庭矛盾、详细聊天和人脸；作品公开展示另行告知并获得相应授权。
- 区分作品数据、最少的操作事件与可选研究数据；撤回、删除、导出、保留期限和备份淘汰都要有方案。
- 明确学校与供应方分别决定哪些目的、谁是处理者/受托方，写入合作约定。
- 不把学生作品、问卷、录音或名册推到 GitHub、普通协作文档或外部 AI 服务；有必要使用时先落实相应合法依据、权限与保护措施。
- 公网部署另核公安联网备案、等级保护等适用要求；不要把“用了某云厂商”当作自动完成自身义务。

## 7. 学校准入不是应用商店审核

教育移动应用可能涉及提供者备案、学校选用和使用管理；学校还会审查隐私、广告、付费、内容及教学必要性。离线桌面工具是否属于该办法中的教育移动应用，应按实际载体确认。[教育移动应用办法](https://www.moe.gov.cn/srcsite/A16/s3342/201911/t20191122_409333.html)、[教育应用规范意见](https://www.moe.gov.cn/srcsite/A16/moe_784/201908/t20190829_396505.html)

建议给校方提供一页清楚材料：适用年龄、一次活动时间、教学目标、游戏化程度、联网和数据流、谁能看到作品、是否收费/广告、退出方式、现场负责人。不要让老师承担判断全国游戏发行合规的责任。

## 8. AI 与医疗宣称是后续独立分支

若提供面向境内公众的生成式 AI 创作助手，需要评估生成式 AI 服务相关规定；生成合成内容标识办法已于 2025-09-01 实施。是否触发备案/登记等义务取决于服务性质和具体适用规定，不能说“调用已备案模型就一定全部合规”。[生成式 AI 暂行办法](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)、[内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)

若软件预期用途变为疾病诊断、治疗或辅助治疗，需进行医疗产品属性与分类核验；并非加上“疗愈”两个字就一律属于某类医疗器械，也不是写“仅供娱乐”就能覆盖实际医疗功能。作为相关监管例子，国家药监局已有人工智能医用软件分类指导原则，但不能把该原则机械套用到所有普通游戏。[药监局文件的政府转载](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202204/t20220408_2669468.html)

## 9. 正式发行的实际工作顺序

1. **确定形态：** 原型视频、功能列表、用户年龄、联网/UGC/付费方式、目标渠道。
2. **主体和伙伴：** 研发著作权、运营机构、出版单位的职责及授权关系。
3. **准备材料：** 内容脚本、素材版权、截图/视频、可审查版本、测试账号、防沉迷说明等。
4. **内容和运行机制审查：** 作品、社区、隐私、未成年人服务、收费规则和运营处置。
5. **省级审查与国家审批/适用的平台测试备案流程：** 选定对应路线，不能互相替代。
6. **渠道接入与上线验收：** SDK、隐私清单、账号注销、审核版本一致性、数据与应急安排。
7. **持续运营：** 更新管理、UGC审核、举报处置、可用性、备份恢复和合规复查。

官方国产游戏审批页列出自受理起 80 个工作日。它不是从今天开始保证 80 个工作日上线；前期准备、省级环节、补正、内容修改和渠道接入需另计。出版社合作、审核运营、法务及云服务费用也没有一个适用于所有项目的统一报价。[审批指南](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html)

## 10. 本项目最合适的顺序

**先内部原型和经校方确认的受控创作活动；有参与和交付证据后，再决定公开游戏、教育软件或机构工具路线。** 三种路线的受众、服务时间和成本不同，技术上保留共同作品格式即可，不宜一开始同时做所有渠道。

正式咨询时需拿着实际原型回答：学生是在用编辑工具还是在接受网络游戏服务？作品是否能在公网被任何人游玩？班级边界如何实施？是否提供内容订阅、广告或付费？这些事实比项目起什么名字更关键。
