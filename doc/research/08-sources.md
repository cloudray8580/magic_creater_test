# 08｜来源索引、方法与未核实事项

调研/访问日期：2026-09-26。来源索引由本套正文中引用的链接生成，避免列入未使用的检索结果。以下“研究”包含论文全文、作者摘要和机构说明，获取深度不同；正文对依赖摘要或访问失败的关键项作了标记。

## 1. 方法

- 用中文和英文检索：厌学、拒学、school refusal、school attendance problems、student motivation、gamified digital mental health intervention、SPARX、MindLight、Mightier、Lumi Nova、Scratch、游戏审批、APP备案、小游戏资质、在线文档保留期限等。
- 学术部分优先系统综述、随机试验及原始研究；产品可用性、范围和付费模式看官方项目/厂商页面；政策看政府正文与官方办事指南；平台要求看官方开发者文档。
- 保留研究人群、比较方式和结局差异；不把市场自述、用户评价、机构采用或监管授权混成同一层次的疗效证据。
- 确认 Scratch 当前编辑器和教程入口；未进行全面功能测试、登录、下载社区作品或发布内容。
- 技术与课程设计属于基于资料的建议，未对产品执行性能测试或对学生开展研究。
- 这是快速证据地图，不是穷尽所有中文数据库、付费期刊和商业供应商的系统综述；没有注册检索协议，也未完成正式偏倚量表逐篇评价。

## 2. 核心结论的可信程度

| 结论 | 当前依据 | 实际限制 |
|---|---|---|
| 已存在游戏化心理干预及商业/公共服务交付 | 随机研究、SPARX、NICE、FDA及厂商资料 | 干预目标和人群各异，不等于能治疗厌学 |
| 关卡共创可能支持自主、胜任和关系 | 动机研究、创造性学习框架、相关产品机制 | 对本产品仍是待验证假设 |
| Scratch 影响广泛 | 官方年报与当前平台介绍 | 用户、触达、项目、月度使用口径不能混用 |
| 公网游戏与课堂时段需先厘清 | 2021 防沉迷通知、游戏审批范围 | 本项目具体分类尚未获主管方认定 |
| 平台试玩/备案存在差异 | TapTap、抖音、Apple、华为、小米、Valve官方文档 | 平台特定规则不代表全国通用豁免 |
| 当前 Scratch 授权需分开评估 | 2026服务条款、当前仓库 LICENSE | 实际采用版本与组合需要专项评审 |
| 钉钉免费正文的统一保留期限未核实 | 产品/权益页、隐私政策、连接器说明 | 不能承诺永久或武断说30天到期 |

## 3. 仍需专项核验

1. 首批年龄、厌学的具体表现、学校/专业伙伴、现场设备。
2. 具体产品属于何种出版/教育应用服务，校内离线与局域网边界如何认定。
3. 微信小游戏、OPPO、vivo、应用宝及主机平台当前后台材料和本项目准入；本轮未逐个平台完成后台核验。
4. 钉钉拟使用账号/团队空间的正文、历史版本、回收站、超限及注销规则。
5. 国外产品在中国的购买、语言、联网、学校许可及医疗监管状态；未以海外许可推导国内可用。
6. Scratch 历史用户作品的授权，以及具体代码/素材采用版本；不默认批量复用。
7. 学生数据处理和作品展示的同意、保留与撤回机制。

访问限制：部分教育部、NICE、期刊和微信文档页面抓取受限，相关结论使用能获得的官方索引、摘要或同机构配套资料；没有把抓取失败解释为政策不存在。飞书页面为动态页面，本轮未核实具体API配额。钉钉相似域名、AI生成营销页和无原始依据的“保存30/180天”文章均未作为承诺依据。
