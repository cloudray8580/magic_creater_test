# 决策与未决事项

## 已决定（2026-09-26）

用户明确委托按已批准设计实施。下面选择是满足既有功能所需的可逆实现细节，未扩大产品范围：

- D01/C01：草稿允许不完整，试玩/提交需完整；固定上限与唯一对象规则保证可校验。采用正交格子移动，不做连续物理或寻路器。
- D02/C02：显式bootstrap老师，教师创建学生、重置/停用；无开放注册。使用随机服务端会话与scrypt凭据哈希。
- D03/C03：本地草稿优先，冲突不合并、不覆盖，用户显式加载或另存；自己作品可复制。
- D04/C04：每作品一个当前展示版本，反馈绑定固定版本，隐藏反馈只给老师；重复提交同修订幂等。
- D05：后端基线无代码，新增后端全量即增量；UT四项覆盖均≥70%满足用户至少70%的要求。

## 原型验证后的选择

- D06：真实Chromium原型已通过编辑、试玩、保存、恢复和分享闭环；React DOM足以完成固定网格玩法，首版不引入Phaser。

## 等待用户信息

- D07：异机备份目的地。已询问Mac仅保存加密文件或已有云存储，未授权新购云服务。
- D08：Docker已有安装但当前账户无权限。在无需主机提权的范围先采用systemd用户服务作为初期运行方式，保留Dockerfile待具备权限后实测。全部工作仍在11700。

年龄、学校设备和正式发行未定不阻塞内部原型，不据此宣称教育有效或支持未经实测设备。

- D09：独立review发现同浏览器多标签同时编辑会互相覆盖本地草稿。采用按账号/作品的单编辑锁，不引入自动合并或多副本界面；Chromium安全上下文实测，其他浏览器需支持Web Locks后方可编辑。
