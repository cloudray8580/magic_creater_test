# 生效契约：M2

来源D21–D25（2026-09-27）；实现前建立。

## C21 文档
V1原有校验与运行不变。新文档schemaVersion=2、rulesVersion=1，gameType为platformer或story，assetPack=storybook-v1。每个文档拥有有序房间、起点、地形格、实体、目标文案、主题、音乐、角色设置；ID在作品内唯一、实体引用必须指向允许类型。仅允许枚举物体/条件/动作，不允许脚本、HTML或外链。未知字段、NaN、超范围、重复/悬空引用返回可读校验错误。草稿可缺起点/终点；完整试玩要求可用起点以及至少一终点。草稿引用未配置可保留，提交/试玩要求完整。
对象位置使用格子坐标，运行器内部位置不回写文档。地形和实体分层；装饰不占用逻辑阻挡。删除被引用实体必须清理/提示引用，禁止默默指向别处。重命名/复制对象不得碰撞ID。
候选容量作为实现限额：横版1房间≤128×32格；探索≤6房间各≤32×24格；共≤300实体、≤4096地形格、≤32故事标记；标题1–60，简介≤240；对话每页≤240字、每人物≤8页、每页≤3选择。模板均能正常完成。

## C22 探索
四向格子逻辑，画面插值；墙/水/关闭门/箱子阻挡。箱子单次只能推动一个且目标空闲。压力板随人物或箱子占据持续生效；开关交互切换并保持。门条件支持任一/全部，来源为收集物/钥匙、开关/压力板或命名故事标记。空条件的门默认打开。对话根据条件按配置顺序匹配，fallback页必有；交付物品显式扣除并设故事标记，已交付不能重复领取。选择文本、目标页和结局是预定义动作。
每个移动/交互是可撤销完整状态快照；包括人物、箱子、背包、机关、故事标记与结束状态。房间重置恢复进入该房间时的完整快照；完整重开回初始。传送到明确房间/坐标，落点必须可站立；避免连续自动传送，需离开触发位置后才能再次触发。玩法不改原始文档。

## C23 横版
固定步长模拟、左右加减速、跳跃、短按/长按、120ms边缘宽容和120ms按键缓冲（调校记录版本）。地面/单向平台/路径平台碰撞语义明确；单向平台只在从上落下时承接。起点与检查点必须有效。危险和跌落快速回最近检查点完整快照（含收集/开关状态），无有限生命惩罚。弹簧在落下接触时弹起；门按条件打开；有时限开关按模拟时间失效；必需收集物控制终点，可选收集物不阻塞。
预览起点/辅助模式显式标识，不能计普通完整通关。失焦暂停并清空按键，弹窗/文本输入不触发游戏；离开销毁场景、监听器与音频。

## C24 视觉与声音
原创二维绘本森林/小屋，两种视角保持统一色彩角色设定；机关开关状态、互动提示和奖励视觉可辨。动画/音效可关闭，信息不只依赖颜色。声音只在用户手势后初始化；用户静音设置保留。React负责界面与低频状态，Phaser负责画布帧循环，关卡逻辑独立可测。样板页复用正式运行器，正式编辑和正式版本播放也复用它。

C24输入补充：两种玩法的对话弹窗都屏蔽游戏键盘快捷键，包括R/Z；弹窗按钮是明确操作入口。资源仍加载时点击画面不提前隐藏进入提示。暂停同步清空按键边沿队列，保留位置/速度；异步音频初始化在销毁后不得恢复定时器。
