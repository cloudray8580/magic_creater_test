# 测试策略

基线 a35c385 无后端代码，因此本轮 src/server/**/*.ts 与服务端使用的 src/shared/**/*.ts 全部为增量范围。Vitest独立单元测试（真实临时/内存SQLite，Fastify.inject，无外部服务）采集v8覆盖；行、语句、函数、分支均设置70%硬门槛，并包含未被导入文件。启动入口同样纳入，不通过排除业务文件抬高覆盖率。

| 范围 | 证据 |
|---|---|
| 关卡与编辑运行 | 不可变状态、边界/非法格式/历史分支的纯函数UT |
| 身份/数据库/API | 独立fixture与临时数据库，角色/班级/作者权限、会话、来源、修订与发布状态断言 |
| 网页 | Playwright在11700真实Chromium执行：教师创建学生→甲编辑保存提交→教师确认→乙通关反馈→甲修改重提→老师撤回 |
| 故障 | 断网本地草稿、重载恢复、文件导入导出、并发修订冲突、用户切换隔离 |
| 部署 | 生产构建、健康/页面访问、进程重启后业务数据、备份恢复、运行服务状态 |
| review | 两个全新上下文只读子agent分别审实现符合性/过度设计及测试/数据权限，修复后复验 |

计划命令：npm run typecheck；npm run test:unit；npm run test:coverage；npm run build；npm run test:e2e。命令最终以package.json为准。

证据需记录代码快照、主机、命令、退出码、测试数、覆盖数及报告路径。报告留在11700，摘要和验收记录提交Git；不上传包含账号密码的trace或运行数据库。
