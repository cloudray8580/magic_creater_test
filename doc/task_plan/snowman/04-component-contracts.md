# M11 实时救援组件契约
C111：地图可先不限时阅读，工具在点击开始前不可操作；开始后准备默认3秒，作者可设置0–180秒，到时自动出发，也可提前出发。准备不融化，出发后持续融化。页面隐藏或主动暂停冻结逻辑时间，暂停不可操作；正常挑战1×，结果回放可加速。
C112：木材修破路1/每格架桥2/雪板2；清水灭火1；路牌1；玩家雪球库存每颗1。可在准备及途中布置。准备全部可撤销；运行中桥/路/牌/雪板/雪球未被雪人使用前可收回退款；水灭火不可回退。非法格、预算不足、已使用项目收回均原子拒绝。行动按逻辑tick和数组顺序有界记录。
C113：四邻格；每格中心先处理当前tick行动，再选择下一格；行进中边锁定。优先当前完整可通的最短路线；否则选择理论可修路线并在首个断口等待。同长按右下左上，路牌限制所在格出边；火7体积/秒，普通及冰1，阴影0.5；普通0.65秒/格，雪板2倍，冰道1.5倍，可组合3倍。体积归零先于拾取或到家，恰好同时到家算失败。路线与下一危险可预览。
C114：地图雪球与玩家放置雪球经过格中心恢复8体积，上限初始体积150%；绝不复活。胡萝卜第一次装鼻。帽子不同样式按经过顺序叠高、无12顶显示硬截断，角色变小也能看见帽塔，不改变碰撞。地图用地形/危险格与独立拾取物层，同格最多一个拾取，最多64顶帽子；玩家雪球不可覆盖作者拾取。
C115：关卡存地图、材料、准备秒数、规则版本，不公开作者操作。服务器用共享时序引擎重放动作，拒绝乱序/未来动作/超预算/非法格/旧修订/虚构胜利。旧V1/V2保留；未发布实验schema3旧草稿按默认值规范化为新规则，旧M11录制和测试不当作新结果。
C116：入门样板第一个必需障碍至少约5秒行程。128×128地图视口绘制，行动或到达格中心决定路线，无变更时复用缓存路径。结果保留布置便于重试；练习可延长准备和降速，发布证明须用正常参数。
