# 组件契约 v1

源于已确认首版设计；下列必要实现细节由用户“按照方案开发、完整跑通”的委托在原范围内确定，追溯见决策记录。

## C01 关卡与编辑运行

JSON结构沿用设计示例，schemaVersion/rulesVersion=1、gameType=grid-exploration、assetPack=builtin-basic-v1；标题1–60字符，网格4–16格/边，单格最多一个对象，id唯一；类型仅spawn/goal/wall/collectible。草稿可缺起终点但每种至多一个，试玩/提交必须各一个；零收集物允许直接到终点，不实现自动寻路判无解。输入大小上限128 KiB，额外结构/未知版本明确拒绝。

移动每次一个正交格；撞墙/越界停留；收集仅一次，全部收集后抵达终点成功，成功后停止移动，重新开始重置。运行状态持有关卡副本。新编辑后清空redo；撤销/重做覆盖名称与素材编辑，历史上限100步。

## C02 身份与请求

bootstrap命令显式初始化一个班级和一个老师，无默认公开密码和注册入口。教师可创建学生、重置密码、停用/启用；停用及改密码撤销已有会话。用户名3–32位小写字母/数字/_/-，显示名1–30字符，密码10–128字符；凭据仅保存盐化哈希。登录失败统一错误，设置登录频率限制。

随机会话令牌仅在HttpOnly、SameSite=Strict cookie中传递；数据库保存令牌摘要，24小时过期，退出即删除。HTTPS配置启用Secure；本机HTTP试用限回环/SSH转发。写请求检查明确允许的Origin，JSON请求只接受对应数据；登录同样校验来源。401未认证，403角色或来源不符，404无访问权的对象，409修订或状态冲突，400无效输入，429限流。

## C03 保存和恢复

作品归属取当前账号与班级；学生只改自己的草稿，老师不改学生原稿。create返回修订1；save携带整数revision，通过条件更新在事务中增加修订，否则409；客户端保留本地修改并提供加载远端、另存副本。

本地草稿按用户id+作品id隔离；同一浏览器以Web Locks限制同作品同时一个编辑标签（关闭或离开编辑自动释放，释放前等待草稿写入），跨浏览器仍用服务端修订冲突；先恢复该用户本地草稿，再主动保存服务器；不把较新的本地草稿静默替换为远端。草稿显示本地成功/失败和服务端状态。导入只接受关卡文档，生成自己名下新作品，不承接外部身份、班级、审核状态；导出只含关卡数据。首版支持复制自己的作品；同伴复制暂不提供。

## C04 版本与反馈

提交从服务器已保存修订生成不可变版本，唯一(project,sourceRevision)，重复提交同一修订返回同一版本。老师可将pending版本变为approved或returned，approved变为withdrawn；已达到目标状态可幂等返回，其他无效转换409。每作品同一时刻最多展示一个版本，批准新版本撤下旧展示，旧内容与反馈保留供作者/老师查看。

作品架与同伴直读仅允许同班approved版本；作者/同班老师能读自己职责内的历史版本，包括撤回状态，此权限不外溢到同伴。同班学生在approved版本上反馈1–1000字符，反馈绑定版本；作者及老师查看该作品反馈，老师可隐藏/恢复，隐藏内容只对老师可见。反馈使用文本渲染。

## C05 部署与数据

网页和/api由同一Fastify应用提供；生产使用构建产物。测试使用临时数据库，试用数据位于仓库外；数据库顺序迁移，重启不重建。/api/health返回健康与版本，不泄露路径/配置。日志不记录密码、cookie及请求正文。

提供SQLite一致性备份、独立恢复验证，检查integrity/foreign keys及业务读回。开发、测试和初期部署均在11700，运行配置不提交凭据。Docker权限及异机备份目标等待用户答复，不影响C01–C04。
