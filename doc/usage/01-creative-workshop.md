# 创作工坊使用指南

适用：电脑＋键盘鼠标，老师组织的封闭小组。当前已自动验证11700的Chromium桌面浏览器；真实学生、Safari、移动端与班级并发试用尚未验证。

## 进入

11700本机打开 `http://127.0.0.1:4173`。Mac通过SSH转发后打开相同地址，应用仍在11700运行：

```bash
ssh -L 4173:127.0.0.1:4173 cloudray@192.168.1.222
```

老师账号在11700的 `~/.config/magic-creater/bootstrap.env`，文件只在主机保存，不在公开Git仓库发布密码。老师在“老师管理”添加学生昵称、账号和初始密码。学生用自己的账号进入；老师的账号负责管理和样板试玩。

## 先体验，再改造

首页按两种玩法展示六个起始模板，每张卡片有游戏截图、机制说明与“先玩一玩 / 开始创作”。同一玩法的模板共享创作能力；来信与灯塔共用解谜路线。经典格子玩法和导入位于可展开的次级入口；顶部链接可直达“我的小世界”。

“灵感样板”也有六个世界。进入游戏后点击“点击进入小世界”。横版用方向键或A/D移动，按住空格跳得更高，E互动；故事用方向键/WASD移动、E交谈、Z撤销一步、R重置房间。失去焦点会暂停；音乐、音效、动态效果可以分别关闭。

|样板|可以尝试的创意|通关提示|
|---|---|---|
|云间邮差|给路线添加岔路、藏邮票、写结束语|24附近E打开灯笼开关，前往终点；邮票可选|
|会移动的桥|改变平台路径、候车点和跨越方式|观察移动平台；也可从高处跳越缺口|
|屋顶秘密|必需收集物、巡逻与高低路线|三枚星星都要找到，平台依次在左侧、较高处和右侧；观察巡逻后再跳|
|森林里的来信|改写人物对话、寄信故事、多房间|先取信，把箱子推到石板上，从箱子旁绕到门；去树屋交信|
|找回灯塔的光|交付物品、任务标记和条件结局|取电池、推箱开门、交给守灯人，再走向灯光|
|我的秘密小屋|邀请别人做客、不同选择与结局|取信并开门，小猫旁按E；可以一起看星星或留下来信|

## 学生创作

1. 在“我的作品”选择创作模板。先改一个地方，随时“试玩关卡”；返回编辑保留编辑视图。
2. 左侧选素材，地图上点击或拖画。图层分为地形、物体、装饰；点选物体看右侧设置。Alt＋拖动或中键平移，“适合窗口”看全图。
3. “框选”在当前图层拖一个框；拖动选区可整体移动。“复制选区”后点击副本左上角。组内机关引用自动指向副本，外部引用保留；传送落点保持原处。起点只有一个，不会复制。越界或覆盖其他同层内容会拒绝整笔操作，撤销一次还原整组。
4. 给门设置“全部/任一条件”，通过地图连接开关、压力板和收集物。故事可增加房间、设置传送落点、编排对话和选择；高级规则仍通过可见选项组合，无须写代码。
5. 主角可选颜色和配件。“自己的图片与涂鸦”支持PNG/JPEG/WebP静态图或直接画画；上传上限2MiB，系统规范到透明画布内，图片不改变碰撞尺寸。每个作品最多引用16张个人图。
6. “保存到服务器”保留草稿；“提交给老师”创建固定版本。作者继续修改草稿，不会改动同伴已经看到的版本。

离线修改只保存在当前浏览器账户的草稿里。需要迁移或长期保留时，用“导出当前草稿”下载带图片的作品文件。遇到其他窗口已经保存的新修订，先导出或另存副本，再决定是否重新载入服务器版本，避免丢掉自己的改动。

## 老师与同伴

老师试玩后“确认展示”，同班同伴才会在“同伴作品”看到它；也可退回、撤回展示和隐藏不合适的反馈。反馈可点“记录当前位置”，作者看到的是该固定版本的地图位置。

作者默认不允许改编。选择“保存并允许同伴改编”后，需要重新提交并经老师展示，新版本才允许同伴复制创作；保留来源署名，素材也复制为独立副本。文件导入的来源只标注为文件自述，不伪装成平台核验。

## 一次小活动的建议

先让学生改造一个已经能玩的模板，互玩后各写一条具体发现，再修改一次。观察是否愿意继续创作、是否能表达自己的想法、是否会利用反馈；不要把通关速度、作品复杂度或点击次数当作厌学改善的证据。本版本尚无真实课堂效果结论。

公开社区、实时多人协作、任意脚本、AI动画生成、完整离线同步和异机备份仍为后续能力。
