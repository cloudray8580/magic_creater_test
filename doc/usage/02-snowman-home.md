# 雪人回家
在首页选择「雪人回家」的「先玩一玩」，或「开始创作」。电脑键鼠优先。

## 玩家
1. 先查看虚线路线。雪人选择满足路牌指向的最短通路，同长路线固定按右、下、左、上搜索。
2. 选修路工具，再点击对应格：破路用1木，断桥每格2木，火堆1水；路牌消耗1牌，放置滑雪板消耗2木。路牌方向可修改；雪人只沿指定出口离开该格。
3. 木材被修路、桥和滑雪板共同使用。可以撤销最近100次布置，或清空后重新安排；材料会退回。
4. 点「出发回家」，随后只观看。可以暂停、1/2/4倍速、滚动地图和定位雪人。页面隐藏时暂停。
5. 每走一格0.65秒，滑雪板拾取后速度翻倍；每秒融化1体积，位于火堆期间为7。到家时体积必须大于0。无路线时留在起点直到融化。
6. 帽子自动叠加，胡萝卜自动装上；装饰不改变速度或融化率。超过12顶帽子显示叠帽与额外数量，避免遮满地图。
7. 失败后返回规划，布置仍保留。可修改再试。

## 创作者
- 宽高分别8–128格，可滚动、缩放、点击小地图跳转。拖动绘制，整笔撤销。
- 画道路、破路、断桥、火堆、装饰和松树；空白与松树不可走。放雪人起点和家会铺上道路。
- 设置初始体积5–300，木材/水/路牌各0–200。缩小地图时若会丢失内容，操作会被拒绝，先擦除边界外内容。
- 沿用自动本地草稿、保存、导出导入、另存副本、永久删除、允许同伴改编等平台能力。
- 提交前必须试玩当前地图并通关；修改地图或材料后需要重新试玩。服务器重新计算该方案，拒绝超预算、不可通关或过期修订。
- 老师确认展示后，同伴可独立规划和试玩，并留下文字反馈。通关方案不会作为答案包含在公开作品里。

准备时间不限；薄冰承重、低矮通道、积雪增重、限时施工模式尚未加入。
