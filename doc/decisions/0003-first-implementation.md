# ADR 0003：首版实现与11700部署

日期：2026-09-26。状态：实现决定已采用；最终试用门槛见验收记录。

## 决定

- 全部开发、依赖、构建、单元与浏览器测试和初期运行位于11700，Mac只负责SSH控制及结果查看。
- 网格原型已经在真实Chromium跑通，采用React DOM绘制，不引入Phaser。仍是一个玩法、多个作品。
- Fastify同进程提供网页和API，SQLite存储会话、作品草稿、不可变版本、审核状态和版本反馈。
- Docker当前账户没有权限，初期采用systemd用户服务：release与仓库dist分离，数据位于仓库外，默认监听回环。保留Dockerfile，容器和ECS迁移尚待实测。
- 本地草稿按用户/作品隔离，同一浏览器同作品只允许一个编辑标签，以Web Locks实现；关闭/离开编辑会释放，释放前等待草稿写入。跨浏览器冲突由服务器revision处理，不自动合并。
- 只读SQLite在线备份，不触发源库迁移；每日本机备份保留14天。异机备份目的地仍待用户指定。

## 审查带来的必要调整

身份并发校验、退出/401清理前端身份数据、教师隐藏反馈隔离、历史试玩保留内存草稿、旧版本可查看、导入对象ID避免碰撞。以上均为已有功能的数据和权限保证，没有增加第二玩法或通用平台能力。

## 不作承诺

不将原型视为厌学治疗方案；不宣称具备公开发行资格。当前自动化验证只覆盖Linux Chromium。域名、HTTPS、课堂设备、容量、数据保留及异机备份应在真实学生试用前落实。
