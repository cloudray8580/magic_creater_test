## 建议先读的结论

**优先验证“老师带领的小范围创作与互玩活动”，再决定是否建设公开游戏社区。** 首个产品可以是一套低门槛的二维关卡创作工具，支持选择模板、改规则、立即试玩、同伴反馈和再次修改。价值假设是恢复自主感、胜任感和归属感；“改善厌学、提高返校率”仍需单独验证。

年龄和试点场景尚未由团队确认。本报告暂按 **12–15 岁、教师带领、电脑或平板、封闭小组、非医疗用途** 做技术估算；案例表保留不同年龄的适用范围，不能直接迁移研究结果。

| 决策 | 当前建议 | 依据与限制 |
|---|---|---|
| 产品定位 | 创作、合作与学习参与支持工具 | 游戏干预对部分症状有研究支持，但未找到足以证明“关卡创作治疗厌学”的直接证据 |
| 起步玩法 | 改造一个能玩的模板 → 同伴试玩 → 具体反馈 → 修改 | 结合自主选择、可见成果和真实受众；防止变成编程考试 |
| 首个使用场景 | 教师带领的小规模班级活动；按实际网络条件选择现场或受控云环境 | 学校准入、产品分类及使用时段仍需确认；技术部署不构成自动豁免 |
| 当前技术基线 | TypeScript + React + Vite；固定网格无需Phaser；Fastify 单应用 + SQLite | 小规模班级服务；详见首版设计，Blockly 和复杂离线同步后续再评估 |
| Scratch 关系 | 借鉴机制；先用现成工具做低成本活动验证，再决定自研 | 当前源码 AGPLv3；代码、品牌、素材、用户作品的授权要分别处理 |
| 分享范围 | 班级内、教师审核、可撤回、作品署名和派生关系可追溯 | 公开 UGC 平台会带来审核、欺凌、版权、身份及隐私成本 |
| 文档 | 仓库 `doc/` 保存经审议的研究和规格；钉钉保存讨论与会议 | 每篇文档只指定一个权威编辑位置，避免自动双向覆盖 |

研究依据示例：2024 年儿科游戏化心理干预荟萃分析纳入 27 项随机试验、2,911 人，抑郁和 ADHD 的平均效应较小，焦虑合并效应未显著。这个结论不能外推成厌学疗效。[研究原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC11420825/)

发行依据示例：网络游戏面向未成年人的服务时间受到明确限制；国家新闻出版署的审批指南也包含网页游戏与网络下载的单机游戏。[2021 年防沉迷通知](https://www.nppa.gov.cn/xxfb/tzgs/202108/t20210830_666285.html)、[国产游戏审批指南](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600725.html)

## 如何使用这些文档

1. 产品与教育伙伴先审阅 01、02、07，确认服务对象和希望改变的行为。
2. 决定试点路径前审阅 04，向学校和当地相关主管方确认具体形态。
3. 开发伙伴先读首版设计和 ADR 0002，再参考 03、05 的研究；验证设备、操作门槛和作品存储后锁定版本。
4. 用 06 的文档流程记录意见；通过后的决定再更新 `decisions/`。

## 调研的性质

这是基于公开资料的快速证据调研与产品建议，不是注册的系统综述，也不是针对某名学生的诊疗建议或具体发行项目的法律意见。论文结果、厂商自述、监管要求和本项目推断在正文中分别标明。未找到证据不等于证明不存在；公开页面不能保证供应商服务、价格或渠道后台要求始终不变。

**调研阶段没有创建学生账户、收集学生资料、发布游戏或购买服务。实现阶段的自动化测试仅使用虚构账号与临时数据库，内部部署库仅初始化老师账号，未导入真实学生资料。** Linux 项目目录是 `/home/cloudray/projects/magic_creater_test`；本套文件应存放在该仓库的 `doc/` 下。
